# Données

- `demo/` : uniquement des jeux de données **synthétiques**, sans identifiants ni informations confidentielles.
- `raw/`, `private/`, `processed/`, `exports/` : répertoires locaux **ignorés par Git**.
- Le premier générateur de données sera développé pendant le projet ; aucune donnée réelle n'est livrée ici.

Un fichier synthétique doit être identifié comme tel dans son nom ou sa documentation, avec la seed et les hypothèses de génération.
